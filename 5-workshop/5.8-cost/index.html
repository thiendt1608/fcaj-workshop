5.8.2 Assumptions

Traffic scenario. 3,000 checks per month (about 100 per day): 2,000 text and 1,000 image messages. Voice and the VLM fallback are not included. 25% of checks are assumed to end on the fast path or in the cache, so only 2,250 call the LLM.

Bedrock tokens (measured). eval/measure_cost.py runs the real pipeline on the eval set and counts tokens per check (184 samples, 17/11/2026):

Unit price (AWS Price List API, ap-southeast-2, 17/11/2026): Qwen3 32B input 0.1545 USD and output 0.618 USD per 1M tokens. The final prompt judge_v3 costs 0.000792 USD per check (docs/eval-report-final.md). If every check called the LLM at p95 token counts, Bedrock would be about 4.6 USD/month instead of 2.1.

5.8.3 Cost optimizations used in the design

MeasureWhereEffect
No VPC, no NAT Gatewayinfra/README.md (rule D1)avoids a fixed ≈ 32 USD/month NAT cost; Lambda reaches DynamoDB, SQS, S3 and the Internet directly
Lambda Function URL instead of API GatewayWebhookFunction in infra/template.yamlno API Gateway charge
DynamoDB on-demand (PAY_PER_REQUEST) with TTLAskFirstTablepay per request at low traffic; expired items (dedup, rate limit, checks) are removed for free
S3 lifecycle: delete donated/ after 30 daysDataBucketstorage does not grow with donated samples
ECR lifecycle: keep the 5 newest images, EmptyOnDeleteinfra/github-oidc.yamlold images do not accumulate; clean-up deletes images with the stack
Low-cost model with a backup only when neededai/config/models.yaml, ADR-001Qwen3 32B on demand; the bigger backup model is called only on escalation (17% of text checks)
Fast path and verdict cacheai pipeline, CACHE# itemsa check that skips the LLM saves ≈ 0.00094 USD (tokens + Guardrail)
Kill switch llm_enabledCONFIG#global / FLAGS in DynamoDBswitches the LLM off without a deploy if the bot is spammed or the budget is at risk
Worker concurrency capScalingConfig.MaximumConcurrency: 5at most 5 jobs (and so 5 LLM calls) run in parallel
No provisioned concurrencyinfra/template.yamlno idle charge; cold starts handled by INIT warm-up instead (see 5.10)
AWS Budgets at 10, 25, 50 USDthe account’s 50 USD Monthly budget (BE-01; the 10 and 25 USD levels added on 25/11/2026)early warning on spend

Not done yet (recommended in docs/results/cost-estimate.md):

  • Set CloudWatch log retention to 7 days for the three functions. Today logs are kept forever.
  • Add a lifecycle policy to the askfirst-dev-ai ECR repository the dev stack uses. The keep-5-images policy in infra/github-oidc.yaml only applies to the askfirst-ai repository; the dev repository has none (checked 25/11/2026).

The biggest cost risk is not the steady state but a stack left running after the workshop, or someone flooding the bot. Use the kill switch if traffic spikes, and run the clean-up in 5.9 when you are done.
